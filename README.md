# 瘟疫公司 · 网页复刻版 (Plague Inc. Web Remake)

一个**纯前端、零依赖**的《瘟疫公司》(Plague Inc.) 复刻版：选一种病原体，从零号病人开始，把瘟疫铺满全世界，赶在人类研制出解药之前把所有人送走。

- 只有 HTML + CSS + 原生 JS，没有框架、没有依赖、没有构建步骤
- 几何数据在运行时从 CDN 拉取 `world-atlas` 的 TopoJSON 并现场解码，所以仓库里只有几 KB 的代码 + 一张参数表
- 175 个真实国家/地区（TopoJSON 世界地图，含人口、气候、医疗水平、机场、港口、陆地邻国）
- 4 种病原体 / 52 个进化节点 / DNA 气泡 / 自发突变 / 政府封锁边境 / 解药竞赛 / 突发新闻播报

---

## 开始游戏

**方式一：本地打开（需能访问 CDN）**

```bash
git clone https://github.com/syy266313/plague-inc-remake.git
cd plague-inc-remake
open index.html      # Windows 直接双击，macOS: open，Linux: xdg-open
```

**方式二：GitHub Pages**

在仓库 `Settings → Pages` 里把 Source 选成 `main` 分支的 `/ (root)`，之后访问
`https://syy266313.github.io/plague-inc-remake/` 即可。手机也能玩，界面按竖屏手机排版。

## 怎么玩

1. **选病原体**：细菌 / 病毒 / 真菌 / 寄生虫，四种玩法差异明显
2. **选难度**：简单 / 普通 / 困难（影响解药研发速度）
3. **点地图选起始国**：点国家即投放零号病人，开局地点决定前 20 天的扩散速度
4. **花 DNA 进化**：传播（水源、空气、昆虫、牲畜、血液）→ 症状（从咳嗽到全面器官衰竭）→ 能力（抗药、抗寒抗热、基因改造）
5. **抢时间**：解药进度条到 100% 就输了。传染要快，但严重性太高会提前惊动人类

顶部 `❚❚ / 1× / 2× / 3×` 调速度，一局 1× 约 8–9 分钟。点病原体名字可以改名。

## 文件结构

```
index.html    页面骨架与 UI 结构（含“正在生成世界地图…”引导层）
style.css     全部样式（黑红配色、扫描线质感、地图叠层、突发新闻卡）
data.js       数据层：拉 TopoJSON → 解码 → 算锚点/邻国，拼出 175 国 MAPDATA；
              附带人工校准的气候/财富/医疗/机场/港口/人口参数表（约 5KB）
game.js       模拟内核 + Canvas 渲染 + 交互（含 //<SIM> 段落，可单独抽出来跑 Node 数值模拟）
```

`data.js` 干的事：下载 `countries-110m.json`（约 107KB）→ 增量解码 arcs 成绝对经纬度 → 把 ring 拼成闭合多边形（1 位小数）→ 用「离国界最远的内部点」网格搜索算出每个国家的锚点和点击热区中心 → 用包围盒 + 顶点距离推邻国 → 合并参数表输出 `window.MAPDATA`，然后才注入 `game.js`。首次打开需要联网一次，之后走浏览器缓存。

`game.js` 里的 `//<SIM>` … `//</SIM>` 之间是**纯逻辑、不碰 DOM**的模拟内核，可以直接在 Node 里加载做平衡性测试：

```js
const src = fs.readFileSync('game.js', 'utf8');
const sim = src.split('//<SIM>')[1].split('//</SIM>')[0];
const api = eval(sim + '\n({ newGame, tickSim, buyNode, canBuy, NODES })');
const s = api.newGame('bacteria', 3);   // 3 = 普通难度
```

## 地图是怎么来的

- 国界多边形：`world-atlas@2/countries-110m.json`，运行时自写 TopoJSON 解码（arcs delta + transform），量化到 0.1°
- 多边形类型区分 `Polygon` / `MultiPolygon`；跨日界线的国家在渲染时按 |Δ经度| > 180° 断笔，避免横贯地图的白线
- 人口：`country-json@1.1.4` 取数后固化进参数表，缺失的 23 个小国手工补齐，全球合计 76.1 亿
- 锚点：不是简单的包围盒中心，而是「多边形内最大内切点」网格搜索得到的点，所以气泡和点击热区都落在国土内部
- 命中判定：经纬度反投影 + ray-cast，多个多边形重叠时取包围盒面积最小的那个（解决莱索托被南非包住这类问题）
